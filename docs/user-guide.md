# User Guide

## Login
- Open the app and go to /login.php.
- Use admin/admin123 or staff/staff123.

## Dashboard
- Shows totals and recent records.

## Modules
- Farmers, Farms, Crops, Plantings, Harvests: use Add form, Edit/Delete buttons, search/filter/sort.

## Reports
- View harvest totals and breakdowns; filter by date.

## Notes
- Staff cannot delete records. Admin can.
